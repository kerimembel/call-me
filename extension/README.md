# CallMe Extension

This extension integrates the **CallMe** service with your editor, allowing AI agents to:
- Call your phone (`CallMe: Call User`)
- Send interactive Telegram messages (`CallMe: Ask via Telegram`)

## Setup

1.  Ensure the **CallMe Server** is running.
2.  Configure the server URL in Settings > CallMe > Server Url.
3.  Use the commands in the Command Palette or instruct your AI agent to use them.

See `ANTIGRAVITY_SETUP.md` in the repository root for full installation instructions.
